API app gọi thẳng Supabase, không qua Vercel. Dùng RPC bảo mật thay vì truy cập trực tiếp bảng.

⚡ QUICK API

Dành cho key QUICK. Response tối giản, phù hợp kiểm tra nhanh.
POST {{SUPABASE_URL}}/rest/v1/rpc/check_key_quick
Headers: apikey: {{SUPABASE_PUBLISHABLE_KEY}} Authorization: Bearer {{SUPABASE_PUBLISHABLE_KEY}} Content-Type: application/json Body: { "p_key": "YOUR_KEY", "p_device_id": "DEVICE_ID", "p_app_version": "1.0.0" }
Response: { "valid": true, "expires_at": "...", "scope": "quick" }
